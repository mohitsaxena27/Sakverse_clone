To run this Vite-React application:

Ensure you have Node.js installed. If not, download and install it from Node.js website.

1) Then, in your terminal, navigate to the project directory and run:

npm install

2) Add Tailwind CSS to your React + Vite project. Run the following command in your terminal:

npm install -D tailwindcss@latest postcss@latest autoprefixer@latest

3) Install routing for your application. You can use React Router for this purpose. Run the following command in your terminal:

npm install react-router-dom

4) To run application you can use and write in the terminal:

npm run dev  (make sure you are in the correct file path!)

5) To add error handling make sure you added

npm install react-error-boundary 

6) To add chart 

 npm install react-chartjs-2 chart.js
